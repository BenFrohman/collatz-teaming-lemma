## Block map

On an odd local minimum n, after k odd-to-odd steps and ℓ extra halves,

    2^{k+ℓ} n' + 2^k = 3^k (n+1).

## The only written tuple

    (n, k, ℓ) = (1, 1, 1).

Then 4n' + 2 = 6, so n' = 1. Orbit 1 → 4 → 2 → 1. That is C_0.
It is a 1-block cycle. Cite: Steiner 1977, n(2^L - 3) = 1 forces n = 1, L = 2.

## What ExistsNontrivial92 asks

A 92-tuple of odd minima and widths with n_93 = n_1 > 1.
One trivial triple is not that tuple. No other tuple is written.
The proposition stays uninhabited.

## What this is not

Not a computed 92-cycle.
Not Δ_cyc(T) = ∅.
Not Collatz.
