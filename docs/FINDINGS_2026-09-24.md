## Type lock

m ≠ K ≠ n ≠ L ≠ Card Ω.

- n : a positive integer
- X0 : verification floor (Barina 2025: 2^71)
- m : local minima = block count
- K : odd-count = Σ k_i
- L : even-count
- Card Ω : cycle length under a named map
- a,b,c : Eliahou semigroup coefficients
