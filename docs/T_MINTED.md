## Definition

    T = (n_1, k_1, ℓ_1, n_2, k_2, ℓ_2, …, n_92, k_92, ℓ_92)

Each n_i is a positive odd local minimum. Each k_i ≥ 1, each ℓ_i ≥ 0.
T is a 92-cycle when it satisfies the block map

    2^{k_i+ℓ_i} n_{i+1} + 2^{k_i} = 3^{k_i} (n_i+1),   i=1,…,91,
    2^{k_92+ℓ_92} n_1 + 2^{k_92} = 3^{k_92} (n_92+1),
    n_1 > 1.

## What was minted

The name T, and the type of T.
Not an inhabitant. No list of 92 odd integers is attached.

The only computed close is (n,k,ℓ)=(1,1,1), which is C_0 and is a 1-block tuple, not T.

ExistsNontrivial92 stays uninhabited.
