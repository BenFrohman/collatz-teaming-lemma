# Tao 2020 notes mapped onto this ledger

Source: Terence Tao, The Notorious Collatz Conjecture (UCLA notes),
https://terrytao.wordpress.com/wp-content/uploads/2020/02/collatz.pdf

Correction of label. In these notes Tao does not call log(3/4) a model mean and does not call it a Lyapunov.

His words:

- “a probability theory calculation reveals that the expected number of divisions by 2 one experiences before reaching an odd number again is equal to two.”
- “the next odd number in the Collatz sequence would be expected to equal approximately 3n/4 on the average.”
- “Thus the average size of the odd numbers in the sequence will decrease towards 1, which supports the validity of the Collatz conjecture.”
- He names the whole argument: “a convincing (but non-rigorous) heuristic argument that predicts the truth of the Collatz conjecture.”

So the object is a **heuristic**: expected next odd ≈ 3n/4, i.e. expected log-change log(3/4)<0. Not a theorem. Not a Lyapunov. Not a named Syracuse random model in this PDF.

On this ledger: keep calling that number the heuristic drift, or Tao’s expected 3n/4. Do not call it “Tao’s Lyapunov.” Do not call it “Tao’s model mean” as if he used that phrase. Our grind phrase “model mean log(3/4)” is our name for the same expected contraction, not his.

The rest of the map is unchanged. Almost-all (Tao 2019) is still not Lemma 2. C_- cycles are still not Δ_cyc(T). Lemmas 1, 2, L stay open.
